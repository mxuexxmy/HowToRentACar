# 高性价比租车指南

讲在中国大陆租 9 座及以下的车，怎样比到当次总价，取还车留什么证据，剐蹭之后先打给谁。23 条，每条写明花掉什么、换回什么、证据有多硬。来源只引法律、规章和政府部门页面。

不用全做。按这次用车会碰到的事翻就行。

规定会改，各平台的合同也不一样。真去提车、报案、投诉时，以那份合同和当地部门的说法为准。

写法参考 [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)。

## 怎么读

每条长这样：

```markdown
### 1. 车一有新伤，先打租车公司和平台
- 成本：一通电话，几分钟。先别把车送去修。
- 说人话：划了、蹭了，就算没撞到别人，也要马上告诉租车公司和平台。
- 收益：买了全险但没及时报备，维修费会落到自己身上。时限以你那份合同为准。
- 证据等级：B
- 来源：合同示范文本、本人这次的经过
- 备注：12 小时这种数字只在写明出处时才用。
```

- **说人话**用日常的话讲后果。数字以「收益」栏为准。
- **证据等级**：A 是打开过的官方文件，B 是还要看这份合同，C 是经历或印象、没有统计。
- 没有官方排行证明某个平台永远便宜。第 1 节让你比的是同一次的结账总价。
- 条目之间用「见第 3 节第 1 条（先打租车公司）」这种写法互相指路。括号里的词要能在那条标题里找到。

## 四种容易混的词

| 词 | 实际是什么 |
| --- | --- |
| 交强险 | 强制保险。赔别人的人伤和财产，不赔你租的这辆车自己的划痕 |
| 车损险 | 保险公司保本车损坏的商业险。租赁公司买没买、免赔多少，看合同附件 |
| 全险、无忧、尊享 | 常常是平台或门店卖的服务，不是保险单。赔付条件由对方写 |
| 报备 | 告诉租车公司，并且在下单的平台里留记录。只告诉店员不够 |
